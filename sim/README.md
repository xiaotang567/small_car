# small_car 软件仿真（不用真车也能调车）

一台装在电脑里的"虚拟小车 + 虚拟赛道"：**188×120 车载相机**、**3D 追车视角**、
和固件**同一套控制链**、并且**说和实车一样的 TCP 协议**（`tools/car_ui.py` 能直接连上来调参）。

> 为什么不是 Unity：这台机器上没装 Unity（也没有 Unity Hub），我无法编译/验证 Unity 工程。
> 这里的 3D 是**纯 numpy 射线投射**实现的（相机和追车视角都是真的透视，不是 2D 俯视图），
> 只依赖 numpy + Pillow，装好 Python 就能跑。

---

## 1. 怎么跑

```bat
:: 只跑仿真（自带窗口：3D 追车视角 + 车载相机 + 遥测 + 启停按钮）
python sim\main.py

:: 想用现有上位机调参（PID 面板、sp/sc 命令都有效）
start python tools\car_ui.py 8086
python sim\main.py 8086
```

```bat
:: 无界面跑 N 秒，检查"能不能跑完一圈 / 会不会出赛道 / 偏离多少"
python tools\sim_test.py 90
```

窗口右边是**车载相机原始画面**（188×120 放大显示，和实车图传一样是灰度二值化前的原图），
左边是 3D 追车视角，下面是遥测：仿真时间 / 实际时间 / 倍速、位置、航向、转速、占空比、舵机、
状态（STR/CUR/LOST）、偏差 e、残差、有效行数、近/远误差、斜率。

## 2. 赛道（`sim/track.py`）

| 要素 | 参数 |
|---|---|
| 一圈 | 上下两条 6m 直道 + 左右两条竖道 + 四个 **R=1.3m** 的 90° 弯，全长 ≈ 27m |
| **十字** | 底部直道 x=3 处，横向支路穿过（±1.3m），路口白色区域是个"+" |
| **圆环** | 顶部直道中间断开，环形道 内径 0.75 / 外径 1.35；环心是**黑岛** ⇒ 必须沿环走 |
| 赛道宽 | 0.5m（半宽 0.25m） |
| 分辨率 | 占用图 2cm/格，一次性栅格化，运行时只查表 |

改赛道就改这几个常量：`TRACK_HALF_W` / `CORNER_R` / `RING_*` / `CROSS_*` / `LOOP_W` / `LOOP_H`。

## 3. 相机（`sim/camera.py`）

和实车那颗总钻风一样：**188×120、装车头前部、低头 18°、水平视场 60°**。

成像链：`反射率(白0.85/黑0.06) → 光照衰减 → 自动曝光(AEC) → 暗角 → 1px 模糊 → 噪声`。
自动曝光是照着实车来的 —— MT9V034 的 AEC **只能开不能关**（我们踩过坑），
所以画面里"白路面刚好饱和到 255"，固件里 `cam_thresh_manual=255` 就是靠这个工作的。

## 4. 控制链（`sim/control.py`）—— 和固件 1:1

| 模块 | 移植自 | 关键常量（和固件一致） |
|---|---|---|
| 扫线 `Scan` | `cam_f4.c` 的 `lf_row_runs/lf_trace_track/cam_track_eval` | 种子行 112、黑缝合并 4px、最多 12 段、残差 >1.6 判弯道 |
| 状态 `State` | `state_f4.c` `drv_state_update` | 直道 w=0.20 / 弯道 w=0.80，占空比上限 50% / 80% |
| 舵机 `Steer` | `servo_f4.c` | 近 112 行 / 远 75 行、`i` 限幅 200、`d` 限幅 60、`de` 限幅 5、回转 400 步/20ms、前馈 `kff=200` |
| 速度 `Speed` | `pid_f4.c` | KP 2.5 / KI 0.45 / I 限幅 3500 / 前馈 5000+1200 / 斜坡 3000RPM/s / 起转踹 40%×2.4s |

**在仿真里调好参数，把数字直接抄回固件**（或者反过来：固件里的值抄到这里对比）。

调参两条路：
- 窗口里只有"启动/停止/复位/清轨迹" —— 轻量；
- **TCP**：`tools/car_ui.py` 连 `sim/main.py 8086`，PID 面板的"应用 sp / 应用 sc"直接改仿真车的参数
  （仿真车是客户端，连上位机，和实车一模一样）。

## 5. 车辆模型（`sim/sim.py`）

- 自行车模型：轴距 0.17m，舵机 ±552 步 ≈ ±22°，`yaw_rate = v·tan(δ)/L`
- 电机一阶滞后（τ=0.12s，满占空比 270RPM），弯道加一点负载 ⇒ 转弯掉速
- 100RPM ≈ 0.35 m/s；编码器转速带噪声
- 物理积分 5ms，控制/相机 20ms（和固件 `CTRL_PERIOD_MS` 一致）

## 6. 现在的实际水平（诚实的现状）

`python tools\sim_test.py 90`：

```
跑了 90 秒：沿赛道 32.05 m（一圈 26.97 m => 1.19 圈）
最大偏离中心线 0.643 m（赛道半宽 0.25 m）
出赛道累计 5866 ms
```

也就是：**能自己跑起来、能过十字和圆环、能绕回来，但会在弯里切内弯、偶尔跑出去**。
这和实车上"转弯偏弱/切内弯"的现象一致 —— 仿真就是拿来复现它、然后在这里调好再上车。

## 7. 没做的（想加就说）

- 端头**白墙**、场地边界外的反光
- 十字/环岛/坡道/斑马线的**元素状态机**（照参考文档 §8，那一步还没做）
- 多圈统计、圈速计时、参数自动扫描（一次跑 20 组 PID 比谁圈速快）
