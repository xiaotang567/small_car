# 存档：台架测试新 DRV888 的模式（FW=2212）

> Git tag：**`drv测试`**（提交 `b87f88d`）
> 想回到这个状态：`git checkout drv测试 -- Core/` 然后编译烧录，
> 或者直接 `git checkout drv测试` 看完整工程。

## 这个存档里有什么（和正常版 FW=2213 的差别）

| 项 | 台架测试版（2212） | 正常版（2213） |
|---|---|---|
| 堵转保护默认状态 | **关**（`g_protect_enable = 0`） | 开（`= 1`） |
| 开环模式下判不判堵转 | 不判（`ctrl_is_open_loop()` 直接跳过） | 同样不判（无害，保留） |
| WiFi 断链是否强制停车 | **不停**（用 `g_protect_enable` 门控） | 停 |
| 上电是否自动转电机 | **是**：开环 40% 占空比（`CTRL_BOOT_RUN_DUTY 4000`） | 否（`= 0`） |
| `pf 0/1` 命令 | 有（保护总开关） | 有（保留，可用） |

## 用途
测新的 DRV888 驱动板：上电就用 40% 占空比驱动电机 1，方便量波形 / 看电机转不转。
固件驱动方式（没变）：**PA2 = PWM 17.0kHz，PB0 = DIR 电平**，±10000 = 满占空比。

## ⚠️ 注意
- 这个版本**一上电电机就转**，上车前先把轮子架空；停止用界面的【停止】/【急停】或发 `w 0 0`。
- 保护关掉以后堵转也一直给占空比，注意 MOS/电机温度。
