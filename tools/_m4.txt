一、WiFi 反复"已连接 → 对方断开 → 已连接"
  上位机日志端口在 6666/6667/6668 乱跳 = 模块在**反复新建 socket**。
  根因：2201 里我在 wifi_f4_retry() 加过"推导 IP 连不上就再连一次写死的 IP"。
        但实际是"模块已经把 TCP 连上了、只是我们握手没等到 ACK"（代码里早有注释的坑），
        于是第二条 CIPSTART 把**已经连好的 socket 拆掉**，去连一个不存在的地址
        ⇒ 上位机看到断开 → 板子又重连 → 无限抖动。
  处理：撤掉那段，恢复"只连 wf_pc_ip 一个地址"。
  （WF_PC_USE_FIXED=0 的自动推导保留：模块 IP 前三段 + 77，热点换网段不用重烧）

二、"有时候获取的图片整幅全白"
  查手册 Table 8 默认值：
    R0xAF = 0x0003  ⇒ **AEC/AGC 出厂就是开着的**
    R0xAD = 0x01E0  ⇒ **AEC 最大曝光 480 行**
    R0xA5 = 0x003A  ⇒ AEC/AGC 目标亮度 58
  188×120 模式（行 bin4）一帧只有 120 行 ⇒ AEC 想调亮时把积分顶到 480 行（远超一帧）
  ⇒ 整帧都在积分 ⇒ **每个像素都饱和 = 255** ⇒ 阈值 255 下二值图整幅全白 ✗
  处理：
    · R0xAD 限到 **110 行**（< 一帧 120）⇒ 物理上不可能再整幅饱和
    · R0xAC 最小曝光 = 2 行
    · `e <n>` 改成写 **R0xA5（AEC 目标亮度）**——手册 P29 写明 R0x0B 只在 AEC 关闭时有效，
      而 AEC 是开着的 ⇒ 以前按"亮度 ±"其实**什么都没改**（这就是按了没反应的原因）
    · CFG 行加了 AD= 回读（正常 110；读到 480 说明没写进去）
  想要完全固定的亮度（不要 AEC 自动调）：把 R0xAF 写成 0x0000，再用 `e <n>` 调 R0x0B。
