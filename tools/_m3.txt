WiFi 连不上：手机热点换网段了，电脑 IP 变成 192.168.103.77（FW=2201）

现象：板子连不上上位机。
查出来的原因：
  电脑现在 WLAN 是 **192.168.103.77**（热点 SSID 还是 iQOO Neo9S Pro+，没变），
  而固件里写死的是 **192.168.212.77**（11-07 那天的网段）
  ⇒ 板子开机后一直在连一个不存在的地址，当然连不上。
  别的都正常：上位机在监听 0.0.0.0:8086、Windows 防火墙三个配置全是关闭、SSID 也对得上。

改法：
- `WIFI_PC_IP` 改成 192.168.103.77（作为兜底）
- `WF_PC_USE_FIXED` 1 → **0**：改成**自动推导**——用"模块自己 IP 的前三段 + 末段 77"
  当电脑 IP。手机热点每次开都会换前三段，但电脑末段一直是 77 ⇒ 以后再换网段**不用改代码重烧**
- `wifi_f4_retry()` 加一层兜底：推导出来的 IP 连不上时，再用写死的 `WIFI_PC_IP` 试一次，
  两条路都不通才认输（防止哪天电脑末段不是 77）
- 版本号 2197 → 2201（环岛那套逻辑仍然是**没有**的状态，这版就是环岛前的行为 + WiFi 修好）

历史网段：189.77 → 53.77 → 212.77 → 103.77（都是热点换网段，电脑末段恒为 77）
